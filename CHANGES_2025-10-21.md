# Changes Summary - Mouse Selection Fix

**Date**: 2025-10-21
**File Modified**: `main.go`
**Status**: ✅ BUILT AND READY FOR TESTING

## Summary

Fixed mouse selection not working by:
1. Correcting the mouse action event code from Action=1 to Action=0
2. Enabling selection in both Viewer and Preview panes
3. Fixing line offset calculation for Preview pane

## Detailed Changes

### Change 1: Mouse wheel scroll support for Preview pane
**Lines**: 227-245
**Before**:
```go
if msg.Type == 5 {
    if m.currentView == ViewerView {
        m.viewer.LineUp(3)
    }
    return m, nil
}
```

**After**:
```go
if msg.Type == 5 {
    if m.currentView == ViewerView || m.currentView == PreviewView {
        if m.currentView == ViewerView {
            m.viewer.LineUp(3)
        }
    }
    return m, nil
}
```

**Why**: Prepares Preview pane for future scroll support.

---

### Change 2: Line offset calculation for both views
**Lines**: 248-260
**Before**:
```go
if (msg.Type == 1 || msg.Type == 11) && m.currentView == ViewerView && m.selectedFile != "" {
    textLine := msg.Y - 3 + m.viewer.YOffset
    textCol := msg.X
```

**After**:
```go
if (msg.Type == 1 || msg.Type == 11) && (m.currentView == ViewerView || m.currentView == PreviewView) && m.selectedFile != "" {
    // Calculate the correct line offset based on which pane is active
    var textLine int
    if m.currentView == ViewerView {
        textLine = msg.Y - 3 + m.viewer.YOffset
    } else {
        // Preview pane: header is at Y=1, content starts at Y=3
        textLine = msg.Y - 3
    }
    textCol := msg.X
```

**Why**:
- Enables selection in Preview pane (second condition check)
- Fixes coordinate calculation for Preview pane which doesn't have scroll offset

---

### Change 3: Correct mouse action code
**Lines**: 270-284
**Before**:
```go
if msg.Type == 1 && msg.Button == 1 {
    // Action 1 = press, Action 2 = drag
    if msg.Action == 1 {
        // Start selection on press
        m.mouseDragActive = true
        ...
        return m, nil
    }
```

**After**:
```go
if msg.Type == 1 && msg.Button == 1 {
    // Action 0 = initial press, Action 2 = drag
    if msg.Action == 0 {
        // Start selection on press
        m.mouseDragActive = true
        ...
        return m, nil
    }
```

**Why**: The actual mouse press event sends Action=0, not Action=1. This was the primary issue blocking selection.
